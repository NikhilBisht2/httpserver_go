My Go HTTP Server

Built from raw TCP. This page is served by your own code.

Endpoint tester (no JavaScript)

Links send a GET request and the browser shows the raw response. Forms send a POST.

GET / GET /health GET /time GET /about GET /nope (404) GET /health?x=1 (query string)

The echo body arrives as message=hello+from+the+browser (form encoding), and your server sends it straight back.

Static file checks

These test your file handler. Open each one and compare to what you expect.

  • hello.txt — text/plain
  • style.css — text/css
  • logo.svg — image/svg+xml
  • logo.png — image/png (binary test)
  • missing.txt — should be 404

Binary check: the image below must display correctly. If it looks broken, your body is being corrupted somewhere.

Security checks (run in a terminal)

Browsers tidy up .. before sending, so use curl:

curl --path-as-is -i http://localhost:8080/static/../main.go
curl --path-as-is -i http://localhost:8080/static/../../etc/passwd

Both must return an error (404 or 403), never your source code.
